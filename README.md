# 🐼 Pandas Playground

Repositório dedicado ao aprendizado, testes e desenvolvimento de rotinas práticas utilizando a biblioteca **Pandas** (Python). O objetivo é centralizar notebooks, scripts de manipulação de dados, limpezas, automações e integração com bancos de dados.

---

## 🛠️ O que você encontra aqui

- **Data Cleaning & Wrangling:** Exemplos práticos de tratamento de *nulls*, duplicatas, parsing de datas e transformações de colunas.
- **Aggregations & GroupBy:** Operações complexas de agrupamento, tabelas dinâmicas (`pivot_table`) e métricas.
- **SQL & Databases:** Conexão, leitura e carga de dataframes em bancos de dados (ex: MySQL, PostgreSQL, SQLite).
- **Automation & Integrations:** Scripts para exportação/importação de dados (CSV, Excel, JSON, Parquet) para rotinas de integração.
